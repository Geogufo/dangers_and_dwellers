# Sources and asset records

## English PDFs

The four PDFs were obtained from the project's [Google Drive source folder](https://drive.google.com/drive/folders/1tVTF7EhBuEyqxSONN9XCI728rUgb1Qm0). Folder metadata was checked on **20 September 2026**. The repository copies preserve the downloaded PDF bytes; filenames were normalized for repository links.

[source-manifest.json](source-manifest.json) records each source URL, source modification time, local SHA-256 checksum, size and page count. A checksum identifies the imported snapshot; it is not an automatic synchronization with Drive.

## Rulebooks

The English extended and short DOCX editions derive from the original Rulebook and the reviewed editorial version, incorporating the author's decisions. They are dated in the repository history, rather than assigned a new game version number.

The current editions include original health and hazard icons, the revised Cassandra procedure, and the final medal check after year 6 income while temporary bonuses are still active. They contain a general worked Event example, without catalogues of individual special-card interactions.
